# 参数账：63.9M 是怎么加出来的


词表 6400、维度 768、8 个 Q 头、4 组 KV、FFN 中间维 2432、8 层：

闭式：

$$
N = \underbrace{V d}_{\text{词表}} + \underbrace{L\left(3d^2 + 3dm + 2d_h + 2d\right)}_{\text{每层}} + \underbrace{d}_{\text{末尾 norm}}
$$

$d=768,\ m=2432,\ L=8,\ V=6400,\ d_h=96$ 代入即得上表。

## 1. 真实的一层（hidden=768）

**a-Attention 子层 → 1,769,664**

| 部件 | 计算 | 参数 |
|---|---|---|
| q_proj | 768 × 768 | 589,824 |
| k_proj | 768 × 384 | 294,912 |
| v_proj | 768 × 384 | 294,912 |
| o_proj | 768 × 768 | 589,824 |
| q_norm | 96 | 96 |
| k_norm | 96 | 96 |


**b-FFN 子层 → 5,603,328**

| 部件 | 计算 | 参数 |
|---|---|---|
| gate_proj | 2432 × 768 | 1,867,776 |
| up_proj | 2432 × 768 | 1,867,776 |
| down_proj | 768 × 2432 | 1,867,776 |

**两个 RMSNorm → 1,536**（`input_layernorm` 768 + `post_attention_layernorm` 768）

**c-一层合计 = 1,769,664 + 5,603,328 + 1,536 = 7,374,528**

## 2. 整体三步

| 部位 | 计算 | 参数 |
|---|---|---|
| ① 词表 | 6400 × 768 | 4,915,200 |
| ② 8 层 | 7,374,528 × 8 | 58,996,224 |
| ③ 末尾 RMSNorm | 768 | 768 |
| **总计** | | **63,912,192 ≈ 63.9M** |
